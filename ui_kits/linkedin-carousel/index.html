template roster · when to use

01 · cover
open the carousel — series eyebrow, hook headline, swipe cue.
02 · content
set up the gap — short lede + body, one accent label.
03 · cta
call to action + wordmark. early CTA so the closer can be a punchline.
04 · big claim
one declarative line as the whole slide. used to break rhythm.
05 · list
numbered framework — five reasons, three principles, four steps.
06 · before-after
two stacked panels with an "in production" hinge.
07 · mistake → correction
struck-through wrong take, then the corrected position.
08 · process
numbered pipeline of steps with gates — show the workflow.
09 · case
client + scope + stack + a single hero outcome number.
10 · metric
one giant number as the slide. before→after context underneath.
11 · punchline
final slide — display quote with one accent word. closes the carousel.
